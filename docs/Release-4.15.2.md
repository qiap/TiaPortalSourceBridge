# v4.15.2

合并 v4.15.1 的虚拟机自动连接与本地界面、索引和构建修复。

- 虚拟机连接保留显式本地端口；主机密钥、日志和隧道状态按配对隔离，复用隧道时核对 SSH 与远端端口。
- 增加 `-LocalOnly` 虚拟机本地启动模式，无需宿主机配对或 SSH 配置。
- 修复转发端口不同导致 I/O、差异审查接口误报跨源的问题：按浏览器 Host 校验 Origin，保持回环主机限制及跨站拒绝，不信任代理转发头。
- 修复 I/O 窄屏表格挤压、首次空状态反馈及导航初始化提示；读取与 Excel 导出有超时处理，旧工程响应不覆盖新目标页面，防止重复导出。
- 区分索引对象内容指纹与完整 XML 文件指纹，修复正常源码快照被误判不一致；保留精确的文件回读证据。
- 同步构建时 Web 资源，修复测试模板重复嵌套；成功打包后清理本次暂存目录，`-KeepStaging` 可保留用于诊断。
- 新增源码仓库 `scripts/Clear-BuildCache.ps1`：默认预览，显式 `-Apply` 才清理超过保留期的指定构建输出；排除工程、配置、恢复记录及发布包，跳过链接和在用目录。

## 下载

- `TiaPortalSourceBridge-4.15.2-Portable.zip`：完整解压后运行 `WebDashboard.cmd` 或 `LaunchWeb.vbs`。
- `TiaPortalSourceBridge-4.15.2-Setup.exe`：安装后使用桌面或开始菜单快捷方式。
- `SHA256SUMS.txt`：ZIP 与 EXE 的 SHA-256 校验值。

两种包均包含 V17/V21 引擎、Web 界面、模板和虚拟机连接辅助脚本。安装包未做代码签名。

## 验证范围

双引擎全量离线回归、浏览器交互、转发端口同源校验、自动配对隔离、构建清理边界、便携包启动，以及安装/升级/卸载生命周期。未向真实 PLC 下载或写入工程；现场虚拟机权限、SSH 网络环境和具体工程仍需相应联调。

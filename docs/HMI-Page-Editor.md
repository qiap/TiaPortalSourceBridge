# HMI 页面编辑器（V17）

在本机控制看板选择工程与 PLC，打开 **HMI 页面编辑**，依次读取 HMI 设备、页面目录，再打开普通页面或模板。

可以点选控件修改文字、位置、尺寸、颜色，以及已有变量、文本列表和已有页面跳转。支持拖动位置、撤销、重做和差异预览。变量绑定只允许切换到已经存在、类型已知且相同的 HMI 变量；不能确认的结构体成员绑定保持原值。

点击 **校验并预览修改** 使用已读取的页面和依赖快照，不再次导出整页或变量表，也不会写入工程。快照校验通过不等于当前工程已通过检查。核对差异和页面范围后，点击 **写入、编译并保存**，后台依次核对最新页面与变量表、预检查、备份、导入、编译、回读修改字段，全部通过才保存整个离线工程。保存也包含该工程中其他尚未保存的修改。不下载到 PLC 或触摸屏。

需要一起修改多个页面时，每页编辑后点击 **加入批量待办**，再打开下一页。每批最多 20 个页面，须属于同一工程、PLC 和 HMI，每页只能出现一次；页面和模板也不能以相同名称重复加入界面待办。点击预览会列出所有页面的字段差异。写入前先核对整批页面的新旧状态；任何一页已变化都会停止整批写入。整批只调用一次导入流程、编译一次、保存一次。导入中途失败可能已有部分页面改变；保留各页备份并报告结果，不自动回滚。

单次操作内复用变量表及目录读取结果，进入导入及编译后回读前清除导出缓存，不跨请求缓存。只改生成编号或 XML 缩进不会触发重复导入；真实文字、引用、属性和对象顺序仍参与比较。整批内容无变化时跳过导入、编译和保存。线条修改同步起终点与位置尺寸，导入前检查几何一致性及控件重名，编译后再核对端点和修改字段。

写入期间显示核对、导入、编译、回读、保存阶段及当前等待时间，结果保留各阶段耗时。状态查询读取任务记录，不排在博途编译队列后；无法确认最终结果时仍显示未知，不能把等待超时当作写入失败。

画布是布局示意，不是 WinCC Runtime：不显示实时 PLC 数值、图片、模板叠加、实际字体或动画。第一版编辑现有控件字段，不新增或删除控件，也不新增事件逻辑。

报警、诊断页面及发现不支持控件的页面只读。经典 WinCC 导出可能遗漏某些复合控件，普通页面写入前仍需确认页面不含这些控件；只读预览本身不证明导出完整。报警视图保留在博途中，不通过此编辑器重建。离散报警表继续走原生 Excel 导入流程。

每个修改方案只允许提交一次。请求断开或结果未知时，使用 **核对最近一次任务** 或 **页面编辑执行记录** 查看原记录，不自动重复写入。导入后编译或回读失败会显示需要核对，并保留备份；不会自动回滚。记录与备份位于配置文件所在目录的 `logs/hmi-editor`。

MCP 提供 `tia_read_hmi_editor`（catalog/read/preview/preview_batch）和 `tia_write_hmi_editor`（已校验方案写入）。`preview_batch` 的 `pages_json` 是 1–20 项 `{snapshot_id, changes_json}`，其中 `changes_json` 为该页全部 `{key,value}` 修改组成的 JSON 字符串。页面快照、方案指纹及工程/PLC/HMI 身份在服务器核验；浏览器只提交受支持字段的修改，不提交整页 XML。

需要保留 TIA Portal 与 Openness 作为后台导入、编译引擎；日常支持范围内的页面编辑可以在浏览器完成。V21/Unified 暂不接入此入口。
